## Вопрос: почему ChangeName изменяет объект, видимый снаружи, а ReplaceHero не заменяет исходную переменную?

При передаче объекта класса по значению копируется ссылка на объект в памяти, а не сам объект

- ChangeName через эту копию ссылки обращается к оригинальному объекту и меняет его имя. Поэтому изменения снаружи видны.

- ReplaceHero создает новый объект (new Hero()) и присваивает его локальной копии ссылки. Исходная переменная снаружи по-прежнему указывает на старый объект в памяти, поэтому она не заменяется.

## Вопрос: почему следующий код не компилируется?

Потому что in передает параметр по ссылке, но только для чтения. Компилятор строго запрещает изменять значение параметра, объявленного с in, чтобы гарантировать безопасность данных внутри методов.

## Шаг 2. ref — Swap

При обычной передаче метод получает копии значений. Метод Swap поменяет метами только свои локальные копии, а оригинальные переменные в вызывающем коде останутся прежними. Чтобы метод мог изменить сами исходные переменные, ему нужно передать ссылку на них в памяти - для этого и нужен ref. Без ref у метода просто нет доступа к оригиналам.
