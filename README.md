## Шаг 2. ref — Swap

При обычной передаче метод получает копии значений. Метод Swap поменяет метами только свои локальные копии, а оригинальные переменные в вызывающем коде останутся прежними. Чтобы метод мог изменить сами исходные переменные, ему нужно передать ссылку на них в памяти - для этого и нужен ref. Без ref у метода просто нет доступа к оригиналам.
